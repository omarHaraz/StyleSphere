# Clothify Admin Dashboard

Clothify is a tailored admin dashboard for clothing stores. This repository contains a responsive admin template for managing products, orders, customers, inventory, and analytics.

## Features

- Dashboard: sales overview, revenue, orders, customers
- Products: manage products, categories, sizes, colors, inventory
- Orders: order list, details, status, shipping
- Customers: profiles and purchase history
- Analytics: sales and revenue charts
- Inventory: stock levels and restock history
